# SOC Password Hash Analysis & Recovery Lab

## Overview

This project is an authorized cybersecurity laboratory exercise focused on password-hash identification, offline password recovery, security analysis, and credential-security recommendations.

The exercise demonstrates practical experience with password-security assessment techniques using Hashcat and John the Ripper.

> **Disclaimer:** This project was performed only in a controlled laboratory environment using provided hashes for educational and authorized security testing purposes.

---

## Objectives

- Identify the likely hash algorithm from hash characteristics.
- Analyze password hashes using their length and hexadecimal structure.
- Perform authorized offline password-recovery attempts.
- Use dictionary-based password recovery techniques.
- Verify recovered passwords against the original hashes.
- Analyze password-security risks.
- Provide recommendations for secure password storage and authentication.
